智能问答系统常见问题

一、系统是什么
智能问答系统是一套面向企业内部文档的检索增强生成（RAG）应用。用户上传制度、手册、产品文档等资料后，可以用自然语言提问，系统先从文档中检索出相关片段，再交由大语言模型组织成答案，并标注答案的出处，便于人工核对。

二、支持哪些文件格式
系统支持 PDF、Word（docx）、Markdown、Excel（xlsx）、CSV 与纯文本（txt）六种格式。扫描件 PDF 会走 OCR 识别流程，识别准确率取决于原图清晰度，建议优先上传文字版 PDF。

三、为什么检索结果不准确
常见原因有三类。第一类是文档尚未完成向量化，在文档列表中状态仍为处理中或失败，需等待或重新上传。第二类是知识库切换了向量模型，导致新旧向量的维度不一致，此时需要清空知识库后重新上传全部文档。第三类是提问方式过于模糊，建议把问题中的关键实体写完整，例如把"报销怎么办"改成"出差住宿费的报销标准是多少"。

四、答案溯源怎么用
每条答案下方会列出引用来源，包含文档名称、片段序号与相似度。点击来源可以展开原文片段，用于核对答案是否被模型曲解。如果答案与引用片段明显不符，说明模型产生了幻觉，应以原文为准。

五、什么是混合检索
系统同时使用三种检索方式：向量检索负责语义相近的匹配，关键词检索负责精确命中专业术语与编号，知识图谱检索负责实体之间的关系推理。三路结果经融合排序后取前若干条作为上下文。任一子检索不可用时，系统会自动降级为其余方式，不会中断问答。

六、API Key 如何配置
进入个人设置页面，选择服务商（阿里云百炼、硅基流动、OpenAI、智谱、DeepSeek 等），填入自己的 API Key，点击测试连接。对话模型与向量模型都通过才算配置成功。部分服务商只提供对话接口而不提供向量接口，这种情况下需要为向量模型单独配置另一个服务商。

七、数据保存在哪里
结构化数据（用户、知识库、文档元数据、问答历史）保存在关系型数据库中，默认使用内置 SQLite 文件库，无需安装数据库服务；如需 MySQL，在配置文件中填写连接信息即可切换。向量数据保存在本地向量库目录中，原始文件保存在上传目录。

八、如何二次开发
后端基于 FastAPI，代码按 core（配置与公共能力）、models（数据模型）、schemas（请求响应结构）、api（接口层）、rag（检索与生成链路）、db（存储适配）分层组织。前端基于 Vue 3 与 Element Plus。所有可调参数集中在系统配置页面，检索阈值、召回数量、模型温度等都可以界面化调整，无需改代码。
